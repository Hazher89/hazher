Navnishan.

Korte, menneskelige adressekoder for Kurdistan-regionen — fra GPS til koder som ERB-A4F2. Bygget for levering, feltarbeid og partnere som trenger stabil adresseinfrastruktur der tradisjonelle postadresser mangler.

Adresse som infrastruktur.

Navnishan gjør posisjon til delbare koder med tillitsnivåer, dekning over distrikter og landsbyer, og API for B2B-partnere.

  • Geohash-baserte koder med by-/distriktshub (48 hub-er + KRI-polygon)
  • Kart: generer, søk og del adressekoder — flerspråklig (sorani, badini, arabisk, engelsk)
  • Claim med GPS-verifisering (≤ 60 m), trust-nivåer og tvisteløsning
  • Primær/hjemmeadresse, «jeg har flyttet», rapportering og admin-revoke
  • Support tickets med tråd, push og admin-hub
  • B2B partner-dashboard og API-monetisering (server)
  • Apple & Google Sign-In via Supabase
