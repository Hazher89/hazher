Personvern — DriftPro (mobilapp)

Sist oppdatert: 17. juli 2026. Gjelder appen DriftPro (Enterprise ERP, HMS, HR og logistikk) på iOS, Android og web. Denne siden kan brukes som Privacy Policy URL i App Store Connect og Google Play Console.

Bedriftsapp: DriftPro er en lukket arbeidsplattform for ansatte og samarbeidspartnere hos kundebedriften (f.eks. Mavi Logistikk AS). Konti opprettes og administreres av bedriftens administrator — det finnes ikke offentlig selvregistrering.
Nettsted vs. app: Informasjonskapsler på hazher.no er beskrevet i personvernerklæringen for nettstedet. Denne siden gjelder appen DriftPro.

1. Behandlingsansvar

DriftPro leveres av Hazher / HAZ.HER ABDULLAH (org.nr. 837 568 382). Kundebedriften (arbeidsgiver) er behandlingsansvarlig for personopplysninger om egne ansatte og partnere. Hazher behandler data som databehandler der det er avtalt. Personvernhenvendelser: kontakt@hazher.no eller hazher@mavilogistikk.no.

2. Hvilke opplysninger appen kan behandle

  • Konto og autentisering: Ansattnummer, navn, e-post, telefon, bedrift, avdeling, rolle, tilgangsnøkler og tekniske sesjonsdata (Supabase Auth).
  • HR / fravær: Fraværstype, datoer, kommentarer, godkjenningsstatus, feriekvoter og tilhørende dokumentasjon.
  • HMS / avvik: Beskrivelse, kategori, alvorlighetsgrad, bilder, valgfri GPS ved innrapportering, SJA, ROS, vernerunder, utstyr og kompetansebevis.
  • Logistikk / partnere: Partnerbedrift, kjøretøy, ruter, SMS-varsler, bilutleiedokumentasjon (bilder av bil, drivstoff, km) og portalbruk for eier/sjåfør.
  • Dokumenter (DMS / personalmappe): Filer, mapper, metadata og tilgangsstyring.
  • Stempling: Stempelinnslag og tilhørende arbeidsdagdata der modulen er aktivert.
  • Varsler: Push-token (Firebase Cloud Messaging) og preferanser dersom aktivert.
  • Teknisk: Logger for drift, sikkerhet og feilsøking (begrenset omfang).

3. Formål

  • Levere HMS-, HR- og driftsfunksjoner for bedriften.
  • Administrere brukere, roller, godkjenninger og partnerportaler.
  • Sende nødvendige varsler (SMS/e-post/push) knyttet til arbeidsoppgaver.
  • Overholde lovpålagte krav (f.eks. arbeidsmiljø) og forebygge misbruk.

4. Rettslig grunnlag

Behandlingen skjer primært på grunnlag av arbeidsavtale / berettiget interesse for drift og HMS, og der det er aktuelt for å oppfylle lovpålagte plikter. Sensitive opplysninger (f.eks. helse i sykmelding) begrenses til nødvendige roller.

5. Tredjeparter (databehandlere)

  • Supabase — database, autentisering, storage og edge functions (EU-region).
  • Firebase Cloud Messaging — push-varsler der dette er aktivert.
  • Dropbox — fillagring når bedriften har koblet lagring.
  • SMS-gateway (f.eks. Sveve) — varsler der bedriften har konfigurert dette.
  • Resend — system-e-post (f.eks. ruteinnboks).
  • Apple / Google — plattformtjenester for appdistribusjon og enhetsvarsler.

Data deles kun i den grad det er nødvendig for å levere funksjonen.

6. Lagring og sletting

Data lagres så lenge arbeidsforholdet / kundeforholdet består og det er nødvendig for formålet. HMS- og fraværsdata kan ha lengre oppbevaring etter lov og bedriftens rutiner. Ved avsluttet kundeforhold slettes eller anonymiseres data etter avtale.

7. Konto og sletting (App Store)

DriftPro er en bedriftskonto. Brukere kan ikke opprette konto selv i App Store-forstand; konto tildeles av administrator. For å be om sletting av konto og tilknyttede personopplysninger:

  1. Kontakt din leder / administrator i bedriften, eller
  2. Send e-post til kontakt@hazher.no med emne «DriftPro — slett konto», og oppgi navn, ansattnummer/e-post og bedrift.

Vi (eller kundebedriften) bekrefter forespørselen og sletter eller deaktiverer kontoen innen rimelig tid, med forbehold for lovpålagt oppbevaring (f.eks. HMS-historikk).

8. Dine rettigheter (GDPR)

Du kan be om innsyn, retting, begrensning, dataportabilitet eller sletting der det er rettslig grunnlag. Kontakt kontakt@hazher.no. Du kan også klage til Datatilsynet.

9. Barn

DriftPro er en arbeidsplattform og er ikke rettet mot barn under 16 år.
