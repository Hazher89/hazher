Nettsted vs. app: Informasjonskapsler på www.hazher.no beskrives i personvernerklæringen for hazher.no. Denne siden gjelder appen KAPRE.

1.Behandlingsansvar

Appen KAPRE leveres av Haz.HER Abdullah (org.nr. 837 568 382), Norge. For personvernhenvendelser: kontakt@hazher.no med emne «Personvern – KAPRE».

2.Hvilke opplysninger vi kan behandle

Avhengig av hvordan du bruker appen:

  • Konto: Navn, e-post/ID fra Apple eller Google, profilbilde og profilopplysninger du velger å legge inn.
  • Annonser: Tittel, beskrivelse, kategori, bilder, pris, sted/adresse for kart, tekniske detaljer (f.eks. kjøretøy) og status (aktiv, solgt, leid, osv.).
  • Bolig / hytte: Tilbudstype (salg, leie, ønskes, ferie), tilgjengelighet, booking- og visningsforespørsler.
  • Chat: Meldinger og metadata knyttet til samtaler om annonser.
  • Favoritter, vurderinger, blokkeringer og rapporter du oppretter.
  • Kundeservice: Saker, kategorier og meldinger du sender til support.
  • Varsler: Push-token og preferanser når du aktiverer varsler.
  • Teknikk: Enhets- og diagnosedata for drift, feilsøking og sikkerhet.

3.Formål og rettslig grunnlag

  • Levere markedsplassen (avtale): publisere, søke, chat, bookinger/visninger.
  • Sikkerhet, misbruksbekjempelse og moderering (berettiget interesse).
  • Push-varsler du har samtykket til.
  • Kundeservice og feilsøking (avtale / berettiget interesse).
  • Lovpålagte krav der det er aktuelt.

4.Deling og underleverandører

Vi selger ikke personopplysninger. Vi bruker blant annet:

  • Supabase — database, autentisering, lagring og edge-funksjoner.
  • Apple / Google — innlogging.
  • Apple Push Notification service (APNs) — varsler på iOS.
  • Karttjenester — visning av sted for annonser (når du bruker kart).

Annonseinnhold du publiserer er synlig for andre brukere av markedsplassen. Chat er mellom deltakerne i tråden (og kan ses av kundeservice/admin ved mistanke om misbruk, i tråd med vilkårene).

5.Lagring

Data lagres så lenge kontoen er aktiv, eller så lenge det er nødvendig for tjenesten eller lovkrav. Når du sletter kontoen i appen (Konto og innstillinger), fjernes persondata som ikke må beholdes. Du kan også eksportere data der funksjonen er tilgjengelig.

6.Dine rettigheter

Du kan be om innsyn, retting, sletting, begrensning, dataportabilitet og protestere mot behandling basert på berettiget interesse. I appen: eksporter data eller slett konto under Konto og innstillinger. Du kan også kontakte kontakt@hazher.no eller klage til Datatilsynet.

7.Sikkerhet

Tilgang styres med autentisering og Row Level Security (RLS) i databasen. Kun du og autorisert kundeservice ser dine private support-saker. Vi anbefaler at du aldri deler passord, BankID-koder eller sensitive betalingsdetaljer i chat.

8.Barn

Tjenesten er ikke ment for personer under 18 år.

9.Endringer og kontakt

Vi kan oppdatere denne erklæringen. Oppdatert versjon finnes i appen og på hazher.no/KAPRE/Privacy/.
